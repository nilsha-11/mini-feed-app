# mini-feed-app
A simple mini-project where users can create posts with custom captions and view them on a live feed. Built to practice full-stack integration and secure coding practices.

## ✨ Features
- **Create Posts:** Add new posts with descriptive captions.
- **View Feed:** Browse through all created posts seamlessly.
- **Secure Configuration:** Backend environment variables are kept safe and hidden via `.gitignore`.

## 🛠️ Tech Stack
- **Frontend:** HTML, CSS, JavaScript (React)
- **Backend:** Node.js, Express.js
- **Database:** Mongooes

## 📁 Project Structure
```text
backend-practice-project/
├── Backend/          # Node.js backend APIs & server configuration
│   ├── src/
│   ├── .env          # Hidden locally (Secured)
│   └── .gitignore
└── Fontend/          # User Interface & client-side logic
```
